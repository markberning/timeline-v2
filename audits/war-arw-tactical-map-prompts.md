# American Revolution — Tactical Battle Map Prompts (ChatGPT image generation)

## How to use
Paste each prompt below into ChatGPT image generation. Save the resulting PNG to `~/Downloads`. When a battle's maps are done, tell Claude (name the battle) and Claude will pull them in, optimize, and wire them up. Each prompt is self-contained — the STYLE HEADER is repeated verbatim in every one so they can be copied one at a time. Generate them battle by battle.

Every prompt is derived ONLY from the existing, fact-checked locator data in each battle's `section-narrative.tsx` (caption + dot names + frame + eyebrow). No tactical facts were invented. Color convention throughout: BRITISH / Crown / allied forces in brick red, AMERICAN / Patriot forces in slate blue. For the Franco-American sieges (Savannah, Charleston) the attackers are blue, British defenders red. For Bennington the Crown raiding force (Hessians/Loyalists) is red.
