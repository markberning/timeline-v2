# French & Indian War — tactical battle map prompts (ChatGPT image gen)

These prompts convert the existing, fact-checked `locator` map data in each battle's
`section-narrative.tsx` into ChatGPT image-generation prompts for clean infographic
tactical maps. Every prompt is faithful to the source caption + dot names + frame; no
tactical details were invented.

## How to use
1. Paste a prompt below into ChatGPT image generation (one map at a time).
2. Save the result as a PNG to `~/Downloads`, named per the suggested filename.
3. Tell Claude when a battle's maps are done so they can be optimized and installed.

**COLOUR KEY (F&I — note: this is the REVERSE of the Revolution).**
BRITISH (and allied) = brick red `#b1422f`. FRENCH (and allied) = slate blue `#2f5fa0`.
Native/Indian contingents take the colour of the European side they fought alongside in
that battle (called out in labels where relevant).

Every prompt opens with the same verbatim STYLE HEADER, then a battle-specific paragraph.
