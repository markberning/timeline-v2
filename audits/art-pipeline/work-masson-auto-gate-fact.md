**[NICE-1] *Les Champs magnétiques* date — "written 1919" vs "published 1920."**
Draft (MsnMethod, ¶2): "Back in **1919**… he had written *Les Champs magnétiques*."
This is defensible: Breton & Soupault composed it in **1919** and it was **published
in 1920**. The draft says "written," which is correct, so this is not an error — but
some sources (incl. the Artforum snippet this pass) tag it "1920" by publication. No
change required; if a reader-facing date is ever surfaced as a stat, use "written
1919, published 1920." Leave as-is.

**[NICE-2] Encyclopedia pull-quote is truncated (intentionally).**
The blockquote in MsnLooking reproduces the Surrealism definition and the first
sentence of the ENCYCLOPEDIA entry but stops before the next sentence ("It tends to
ruin once and for all all other psychic mechanisms…"). The reproduced text is
**verbatim and accurate**; a partial pull-quote is fine and there is no ellipsis
needed mid-sentence since it ends on a clean sentence boundary. No change required —
recording only so a later editor doesn't "restore" it thinking it was dropped by error.
