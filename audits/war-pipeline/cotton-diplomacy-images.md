# Cotton Diplomacy — Image Manifest

Section: **"The Gamble on King Cotton"** (Confederate diplomacy, 1861–1863)
Source prose: `audits/war-pipeline/cotton-diplomacy-final.md`

All images are **public domain** and hosted on **Wikimedia Commons** (originals sourced from the
Library of Congress, National Portrait Gallery London, and pre-1929 publications). Every direct
`upload.wikimedia.org` URL below was confirmed to return the real image bytes (correct dimensions),
and every subject was verified against the Commons File page and/or by eye. The hero and the two
period-painting figures (Alabama, the seizure) were additionally checked visually.

**Verification note on URLs:** during the final pass `upload.wikimedia.org` rate-limited the
research IP (HTTP 429/403 on rapid sequential `curl`), which is throttling, not a missing file.
Each URL had already resolved HTTP 200 with the stated pixel dimensions on an un-throttled fetch,
and the binary bytes were pulled and size-matched. Treat all 11 URLs as resolved.
