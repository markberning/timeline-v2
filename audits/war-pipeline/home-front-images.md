# Home Front — Verified Image Manifest

Section: **"A Rich Man's War, A Poor Man's Fight"** (the Home Front — civilian life,
the draft, the war economies, 1861–1865).
Source narrative: `audits/war-pipeline/home-front-final.md`.

All images below are **PUBLIC DOMAIN** and hosted on **Wikimedia Commons**. Every
direct `upload.wikimedia.org` original URL was confirmed to resolve via the Commons
`imageinfo` API (real dimensions returned, listed under each entry). **Not downloaded,
not committed** — this is a manifest only.

PD basis used here:
- **Pre-1929 publication** → public domain in the U.S. (every Harper's Weekly / Frank
  Leslie's engraving here was published 1861–1863, well before the 1929 cutoff).
- **U.S.-government work / unit of U.S. currency** → not eligible for copyright (the
  greenback and the Confederate note are reproductions of currency; the engraving
  *content* is in any case pre-1929).

- **orientation:** PORTRAIT.

### 9. greenback-dollar
- **key/slug:** `greenback`
- **filename:** `home-front-greenback.jpg`

  issued as legal tender." Crop to the note rectangle for a landscape figure.
