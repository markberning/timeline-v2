## SHOULD-CONSIDER (non-blocking improvements)

1. **Sherman's stall as a reconnaissance failure (one clause).** Web sources (WP, ABT
   *Fight for Tunnel Hill*) stress that Sherman didn't just get out-fought — he attacked the
   *wrong ground*. Bad maps/poor recon led him to seize a **detached hill separated from the
   main ridge by an unexpected ravine**, believing it was Tunnel Hill. The draft renders the
   stall as purely Cleburne's defensive skill (the-plan ¶4 + "Meanwhile" calls Cleburne's win
   "clean"). That's true but half the picture — the terrain surprise is *why* the hammer
   couldn't fall as designed. A single clause ("Sherman, misled by bad maps, had taken a
   detached spur and found a ravine between him and the real Tunnel Hill") would make the
   stall make sense rather than read as inexplicable. Not blocking — the *outcome* (stall, no
   breakthrough, ~2,000 casualties) is correct as written.

2. **Bragg's pre-battle weakness was self-inflicted (one clause, optional).** Web sources note
   Bragg had **detached Longstreet's corps to Knoxville** before the battle, thinning the very
   line that broke, and was leading an army whose generals had openly revolted against him after
   Chickamauga. The draft mentions Bragg "lost his command with it" (the-meaning ¶2) but never
   that his army was *already* hollowed and demoralized walking in. This deepens "an army that
   broke and ran" — but it risks pulling focus and re-telling Chickamauga's aftermath, so treat
   as optional color, not a gap.

## Fact-pack blind spots (flag to fact-checker / pack maintainer)

**A. Sherman's reconnaissance failure is absent from the fact pack.** §5.2 frames Tunnel Hill
purely as "Cleburne repulses Sherman." The fact pack never gives the author the detached-hill /
bad-maps / unexpected-ravine detail that the public sources foreground. The author can't write
what isn't in the pack — so the gap (checklist #22) traces straight to the pack, not the author.
Recommend adding one bullet to §5.2.

**B. The "two-line split" is attributed only to Bragg's engineers, not to Bragg's indecision.**
Web (Warfare History Network, ABT) frame the split deployment as a symptom of *Bragg's inability
to decide where to concentrate* — and name the specific mechanism (Breckinridge fortifying the
crest while Bate/Anderson moved *half* their divisions up, leaving the rest in the base pits).
The fact pack §5.1 + draft both correctly carry the military-crest error but present the split as
a flat engineering choice. The "half-and-half, couldn't decide" framing is a richer, well-sourced
account of *why* neither line was strong. Optional enrichment for the pack; the draft's version is
not wrong.

**C. (Confirm, not a gap) Bragg's exit was a *resignation accepted*, not a firing.** Web sources
say Bragg **resigned** (Nov 28–30) and Davis accepted it "without comment," replacing him
eventually with Johnston. The draft says "relieved soon after" with a [VERIFY] flag — fact pack
§9 already flags the date/circumstance. Flagging here only so the fact-checker resolves "relieved"
vs. "resigned" precisely; comprehensiveness-wise the beat IS present.
